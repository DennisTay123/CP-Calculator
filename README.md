# CP Calculator (Cost Performance Calculator)

**CP Calculator** is a lightweight, responsive web application designed to help users compare the **cost performance (CP)** of different products. It calculates cost-per-unit values across multiple customizable product categories to highlight which options offer the best value for money.

## 🔍 Purpose

This tool is ideal for consumers and budget-conscious users who want to quickly evaluate and compare similar products based on price and quantity, whether for groceries, hardware, supplies, or any cost-per-unit scenario.

## 🌟 Features

- 📊 **Cost-Per-Unit Comparison**: Calculates CP values and visually marks the **best** items.
- 📁 **Dynamic Categories**: Add and remove product categories with collapsible sections for better organization.
- 🌓 **Dark Mode Support**: Toggle between light and dark modes, or automatically match your system theme.
- 🧮 **Auto Calculation**: Instantly updates values as you type, with visual highlights.
- 📱 **Responsive Design**: Optimized for both desktop and mobile devices with mobile-friendly table views.
- 🔧 **No Backend Required**: All functionality runs in the browser with JavaScript—no server or database needed.
- 🚀 **Deployable to GitHub Pages**: Purposefully built as a standalone HTML/CSS/JS web app, making it ideal for static site hosting platforms like GitHub Pages.

## 💡 Why This Design?
This application is intentionally designed to be a single-page and dependency-free tool for ease of deployment on GitHub Pages or any other static hosting platform. All logic is handled via vanilla JavaScript, and the UI is powered by plain HTML and CSS—no frameworks required.
